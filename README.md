# ISH Habit Tracker

A modern habit tracking web application designed to help users build consistency and monitor daily progress.

## Features

- Habit Management
- Progress Analytics
- Interactive Charts
- Responsive UI
- Local Storage Support
- Modern Glassmorphism Design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
